# 整合取舍

1. 以 fanhao375 的 HD1910 接入为基线，而不是把三个同源工程堆在一起。
2. 其 M6 参数与 LuwuDynamics 原文件哈希一致，故只保留训练工程中一份；SHA-256 为 `ef2d51adfb1cc0831b9b02ca19aa9176fceecdf725148d084378d7d9a64afceb`。
3. HD1910 入口设置 kp_fw=5、电压 7.4–8.0 V、下限 7.0 V、延迟 3–6 仿真步；这些是训练基线，不是给实机写寄存器的指令。不要误用保留的 XL330 默认配置。
4. 不复制 XgoDuck 的 0.8 kg 整机惯量、默认站姿和策略到我们的飞特结构。需要测量我们自己的整机质量、惯量、关节方向及限位。
5. 保留 fanhao375 对飞特 BAM 目标历史初始化的处理，不用另一个仓库的相似文件覆盖。
6. 训练依赖沿用原锁文件；没有为了去重而混用另一个环境的 vendor/bam 和锁文件。
7. JoyandAI 保留技术来源链接，不混入许可有歧义的图纸。
8. 机械以飞特 v2.1 CAD 为准；原始 2026-09-15 3MF 仅供参考，需逐件核对后生成我们自己的打印工程。

本轮没有执行设备运动、刷机、EEPROM 写入、GPU 训练或付费云任务。尚缺的 Zero 3W 运行时需要后续单独引入并验证，当前不是完整可部署固件合集。
