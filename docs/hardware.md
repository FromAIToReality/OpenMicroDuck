# 当前硬件与待核对项

已确认采用：Radxa ZERO 3W、飞特 HD1910 舵机、微雪控制模块、LSM6DSV16X IMU 模块。

TTL 半双工接口和针序、供电能力、舵机固件/工作模式/数量、IMU 接口引脚、实际板卡安装尺寸、电池和电源系统。

摄像头、语音与喇叭不是本阶段已购硬件，不列为必备。不能根据旧 BOM 默认所有设备已经购买。

LSM6DSV16X 模块不能直接接入舵机三线总线。需要确定主控 I2C/SPI 直连，还是另做带 MCU 的桥接板。仓库中的桥固件只是一条参考路线，不意味着我们已拥有相应 PCB。

结构件计划使用 PA6-CF，软脚垫使用 TPU。材料更换后需复核尺寸和支撑；上游 PLA 工程不能直接用于当前耗材。
